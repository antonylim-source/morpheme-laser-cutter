## 1. 프로젝트 개요

### 1.1 목적

**Morpheme Laser Cutter**는 영어 **합성어(Compound Word)**를 형태소(Morpheme) 단위로 분해하는 학습을 게임화한 웹 기반 POC(Proof of Concept)입니다.

학습자는 괴물 몬스터 몸에 새겨진 합성어(예: `earthquake`)의 **형태소 경계(가운데)**를 레이저(스와이프)로 정확히 자르면, 두 어근(`earth` + `quake`)과 대응 이미지가 분리되며 학습 피드백을 받습니다.

### 1.2 핵심 학습 목표

- 합성어를 두 형태소로 **시각·운동 감각**과 연결해 이해
- 형태소 경계 위치를 **공간적 정확도**로 인식
- 반복 플레이를 통한 어휘·형태소 패턴 습득

### 1.3 타깃 사용자

- 초·중등 영어 학습자 (연령별 난이도 3단계 제공)
- 태블릿·PC 브라우저 환경 (터치·마우스 스와이프)

```
└── docs/ (상위)         # 게임 규칙·화면비율 명세
```

### 3.2 화면 스케일링

`StageScaler` 컴포넌트가 1280×800 `#stage`를 브라우저 크기에 맞게 **비율 유지 스케일**합니다.

```
scale = min(viewportWidth / 1280, viewportHeight / 800)
transform-origin: top center
```

- `visualViewport` API로 모바일 URL 바·줌 보정
- iOS Safari 핀치 줌 차단 (`gesturestart` preventDefault)
- 내부 레이아웃은 고정 좌표 — 스케일만 변경

### 3.3 상태 관리

| 레이어 | 방식 | 담당 |
|--------|------|------|
| 게임 코어 | `useReducer` (`useGameState`) | status, score, failCount, currentWord |
| 세션 | `App.tsx` local state | wordsDone, combo, gameOver, ageMode |
| 캔버스 | Canvas ref + requestAnimationFrame | 몬스터 접근·레이저·파편 물리 |

**게임 상태 (`status`)**

| 값 | 의미 |
|----|------|
| `idle` | 시작 화면 |
| `playing` | 플레이 중 |
| `success` | 정답 슬래시 |
| `fail` | 오답 (1~2회) |
| `hint` | 3회 Miss → 힌트 모달 |

## 4. 게임플레이 명세

### 4.1 플레이 흐름

```
[시작 화면] → 난이도 선택 → Start!
    ↓
[몬스터 접근] → 단어 노출(95%+) → 스와이프로 슬래시
    ↓
정답 → +100점, morpheme 분리 연출 → 3초 후 다음 단어
오답 → 몬스터 커짐·가속 → 0.9초 후 재시도
3회 Miss → 힌트 모달 → 1.5초 후 다음 단어
    ↓
10단어 완료 → [게임 오버] → 별 등급·총점 표시
```

### 4.2 슬래시 판정

**정답 조건**

```
diff = |touchX - boundaryPixelX|
정답: diff ≤ tolerance (난이도별)
```

| 난이도 (UI) | 내부값 | 허용 오차 |
|-------------|--------|-----------|
| Easy | `young` | ±20 px |
| Normal | `standard` | ±18 px |
| Hard | `advanced` | ±12 px |

**슬래시 인정 조건**

- 게임 상태: `playing`, 게임 오버 아님
- 세로 스와이프: Y 이동 > 30px
- 단어 노출: `approachProgress ≥ 0.95`
- 판정 X: 스와이프 궤적이 `wordY = 400`에서 교차하는 지점

### 4.3 점수·Combo·Miss

| 항목 | 규칙 |
|------|------|
| Score | 정답 시 +100점, 세션 누적 |
| Combo | 연속 정답 단어 수 (fail/hint 시 0 리셋) |
| Miss | **현재 단어** 오답 횟수 (0~3) |

**Miss에 따른 난이도 상승** (Pick your level과 무관)

| failCount | 몬스터 속도 | 크기 배율 | 힌트 |
|-----------|-------------|-----------|------|
| 0 | 220 px/s | ×1.0 | — |
| 1 | 297 px/s | ×1.5 | 단어 불꽃 연출 |
| 2 | 374 px/s | ×2.25 | 경계 노란 점 |
| 3 | 451 px/s | ×3.375 | 힌트 모달 (morpheme 분리 안내) |

### 4.4 몬스터 티어 (진행도)

`wordsDone`에 따라 몬스터 이미지·스프라이트 시트가 교체됩니다.

| 완료 단어 | 몬스터 | 구간 |
|-----------|--------|------|
| 0~2 | monster_4 (거미) | 도입 |
| 3~5 | monster_1 (골렘) | 중반 |
| 6~8 | monster_3 (그리핀) | 후반 |
| 9 | monster_2 (돌 야수) | 최종 보스 |

- 접근 속도: 완료 단어당 **6%** 가속 (`MONSTER_SPEED_RAMP_PER_WORD`)
- 원근 접근: 멀리서 작게 → 가까워질수록 가속 확대

### 4.5 세션 타이밍

| 이벤트 | 대기 시간 |
|--------|-----------|
| 정답 후 다음 단어 | 3,000 ms |
| 힌트(3 Miss) 후 다음 단어 | 1,500 ms |
| 오답 후 재시도 | 900 ms |
| 한 판 단어 수 | 10 |
| 게임 오버 별 | `floor((wordsCompleted / 10) × 3)` (최대 3개) |

### 4.6 키보드 단축키 (개발용)

| 키 | 동작 |
|----|------|
| `Space` | 정답 슬래시 (데모) |
| `H` | 3회 Miss 유도 |
| `R` | 게임 리셋 |
| `?` | DEV: tolerance·경계선 오버레이 |

## 5. 학습 콘텐츠

### 5.1 단어 데이터 구조

```typescript
interface CompoundWord {
  id: string
  full: string           // "earthquake"
  morpheme1: string      // "earth"
  morpheme2: string      // "quake"
  boundaryIndex: number  // 형태소 경계 (0-based)
  image1, image2: string // 어근별 PNG
  effect1?, effect2?    // spin | shake | pulse | none
}
```

## 6. UI/UX 구성

### 6.1 주요 화면

| 화면 | 컴포넌트 | 설명 |
|------|----------|------|
| 시작 | `StartScreen` | 로고, 규칙 안내, Pick your level, Start 버튼 |
| 게임 | `GameCanvas` | Konva 캔버스 — 몬스터·단어·레이저·파편 |
| HUD | `ScoreBoard` | Score / Combo / Miss 배지 |
| 피드백 | `FeedbackPopup` | SLICE! / GREAT! / SUPER! / Oops! / BOOM! |
| 분리 연출 | `SplitAnimation` | morpheme 이미지 + 효과 |
| 힌트 | `HintOverlay` | Miss 단계별·3회 Miss 모달 |
| 종료 | `GameOverScreen` | 총점, 격파 수, 별, Play Again |

### 6.2 접근성·UX

- `prefers-reduced-motion` 지원 (Framer Motion `useReducedMotion`)
- 음소거 토글 (BGM + 효과음)
- 시작 시 이미지 프리로드 (몬스터 시퀀스 깜빡임 방지)
- BGM: 사용자 클릭(Start) 시 재생 (브라우저 자동재생 정책 준수)
- 진동 피드백 (`navigator.vibrate`, 모바일)

### 6.3 사운드

| 종류 | 구현 |
|------|------|
| 효과음 | Web Audio API 오실레이터 (slice, crack, success, combo, deflect, grow) |
| BGM | `useBgm` — HTML Audio, idle/gameOver 시 pause |
| 발소리 | 몬스터 접근 박자마다 `stomp` (접근도 비례) |
